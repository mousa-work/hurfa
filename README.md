# حُرفة — سوق الخدمات المصغّرة العربي 🛠️

موقع سوق خدمات مصغّرة عربي متكامل (مشابه لـ Fiverr / خمسات) مبني بـ HTML وCSS وJavaScript فقط — **بدون أي أدوات بناء أو خادم**، يعمل مباشرة من المتصفح.

## ✨ المزايا

- **واجهة عربية كاملة (RTL)** بتصميم عصري متجاوب مع الجوال
- **24 خدمة جاهزة** موزعة على 8 تصنيفات (برمجة، تصميم، تسويق، كتابة، فيديو، صوتيات، أعمال، ذكاء اصطناعي)
- **بحث وتصفية**: حسب التصنيف والسعر والتقييم ومدة التسليم، مع خيارات ترتيب متعددة
- **صفحة خدمة كاملة**: معرض صور، 3 باقات (أساسية/قياسية/مميزة)، تقييمات، بطاقة البائع، خدمات مشابهة
- **حسابات مستخدمين**: تسجيل ودخول (تُحفظ البيانات في `localStorage` بالمتصفح)
- **طلب وشراء**: صفحة إتمام طلب مع ملخص السعر ورسوم المنصة وتأكيد الطلب
- **لوحة تحكم**: إحصائيات، متابعة الطلبات وتأكيد الاستلام، إدارة الخدمات، المفضلة
- **كن بائعاً**: أضف خدمتك الخاصة بباقاتها وتظهر فوراً في التصفح والبحث
- **مفضلة ومراسلة البائع** ونوافذ منبثقة وإشعارات (Toast)
- **صورة شخصية إلزامية عند التسجيل** (تُصغَّر وتُحفظ محلياً) وتظهر في الترويسة ولوحة التحكم والملف العام
- **سابقة الأعمال**: لكل بائع معرض أعمال منجزة يطلع عليه الجميع، وكل صورة تحمل علامة «أُنجز عبر حُرفة ✓» على طرفها، مع عارض مكبّر — ويستطيع المستخدمون إضافة أعمالهم من لوحة التحكم
- **لوحة إدارة كاملة** (`admin.html`): إحصاءات المنصة والإيرادات والرسوم، جميع المستخدمين والطلبات والخدمات والأعمال والرسائل، مع صلاحيات إكمال/إلغاء الطلبات وحذف الخدمات
  — دخول المدير التجريبي: `admin@hurfa.com` / `admin123`

## 🚀 التشغيل

لا يحتاج الموقع أي تثبيت — افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
# بايثون
python3 -m http.server 8000

# أو Node.js
npx serve .
```

ثم افتح: `http://localhost:8000`

## 📄 الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية: البطل، التصنيفات، الخدمات الشائعة، كيف تعمل المنصة، آراء العملاء |
| `browse.html` | تصفح الخدمات مع الفلاتر والترتيب والبحث |
| `gig.html?id=1` | تفاصيل الخدمة والباقات والتقييمات |
| `seller.html?id=1` | الملف الشخصي للبائع وخدماته |
| `login.html` / `register.html` | تسجيل الدخول وإنشاء الحساب |
| `checkout.html` | إتمام الطلب والدفع (تجريبي) |
| `dashboard.html` | لوحة التحكم: الطلبات، الخدمات، المفضلة |
| `create-gig.html` | إضافة خدمة جديدة كبائع |

## 🗂️ البنية

```

├── css/
│   └── style.css       # نظام التصميم الكامل
└── js/
    ├── data.js         # البيانات: التصنيفات والبائعون والخدمات
    └── app.js          # المنطق المشترك: الجلسة، الترويسة، المفضلة، الطلبات
```

## ⚠️ ملاحظة

هذا موقع تجريبي (Front-end فقط): الحسابات والطلبات والخدمات المضافة تُحفظ في متصفحك عبر `localStorage` ولا تُرسل لأي خادم. لا تستخدم كلمات مرور أو بيانات دفع حقيقية.
